# APTV Recovery

**Как откатить APTV на предыдущую версию на iPhone**

[English](README.md) | **Русский**

---

Официального способа откатить приложение через App Store нет. Но если приложение уже было скачано на ваш Apple ID, его старые сборки по-прежнему хранятся на серверах Apple. Эта инструкция показывает, как получить IPA нужной версии с помощью консольной утилиты `ipatool` и установить его на iPhone через Apple Configurator.

Проверено на: macOS, iPhone 13, iOS 26.7.1, APTV 1.5.13 → 1.5.12.

Вы скачиваете приложение, которое уже есть в вашей истории покупок, под своим Apple ID. Джейлбрейк и сертификаты разработчика не нужны.

## Что понадобится

- Mac с macOS и установленным [Homebrew](https://brew.sh)
- iPhone и кабель
- Apple ID, на котором когда-либо было скачано APTV (в примерах — `user@example.com`, подставьте свой)
- Включённая двухфакторная аутентификация (код придёт на доверенное устройство)
- 15–20 минут времени

## Шаг 1. Установите ipatool

Откройте Терминал и выполните:

```bash
brew tap majd/repo
brew install ipatool
```

Проверьте установку:

```bash
ipatool --version
```

## Шаг 2. Войдите в App Store

```bash
ipatool auth login -e user@example.com
```

Введите пароль Apple ID, затем код двухфакторной аутентификации, который придёт на iPhone или Mac. При успехе появится `success=true`.

## Шаг 3. Найдите приложение и его bundle ID

```bash
ipatool search APTV
```

В ответе будет несколько похожих приложений. Нужное — с издателем Suzhou Xiying Guangnian Technology Co., Ltd:

```json
{"bundleID":"com.kimen.aptvpro","id":1630403500,"name":"APTV", ...}
```

Запомните bundle ID: `com.kimen.aptvpro`.

## Шаг 4. Получите список всех версий

```bash
ipatool list-versions -b com.kimen.aptvpro
```

Команда вернёт массив `externalVersionIdentifiers` — внутренние ID всех сборок, отсортированные от самой старой к самой новой. Последний ID в списке — текущая версия в App Store, предпоследний — предыдущая и так далее. Пример (конец списка):

```text
..., "889242372", "891251494", "892296607", "893159945"
```

## Шаг 5. Определите, какой ID соответствует какой версии

ID не совпадают с номерами версий, поэтому расшифруйте нужные:

```bash
ipatool get-version-metadata -b com.kimen.aptvpro --external-version-id 892296607
```

Ответ:

```text
displayVersion=1.5.12 externalVersionID=892296607 releaseDate=2026-09-30T18:22:44Z success=true
```

Команда может выполняться 40–60 секунд — это нормально. Проверьте 2–3 последних ID, пока не найдёте нужную версию.

| external-version-id | Версия APTV | Дата релиза |
|---|---|---|
| 893159945 | 1.5.13 (текущая) | октябрь 2026 |
| 892296607 | 1.5.12 | 30.09.2026 |
| 891251494 | предыдущая | — |

## Шаг 6. Скачайте нужную версию

```bash
ipatool download -b com.kimen.aptvpro --external-version-id 892296607 --platform iphone -o ~/Downloads/APTV_1.5.12.ipa
```

Флаг `--external-version-id` обязателен — без него скачается последняя версия.

Ответ `success=true` означает, что IPA лежит в папке «Загрузки». Строка `purchased=false` — это норма: приложение уже было в вашей истории покупок, повторная «покупка» не потребовалась.

Если ipatool сообщит, что лицензии нет, выполните команду ниже (приложение бесплатное) и повторите скачивание:

```bash
ipatool purchase -b com.kimen.aptvpro
```

## Шаг 7. Установите Apple Configurator

Apple Configurator — бесплатная официальная утилита Apple. Откройте Mac App Store, найдите «Apple Configurator» (издатель Apple) и нажмите «Получить». Либо из Терминала, если установлен `mas`:

```bash
mas install 434290957
```

## Шаг 8. Установите IPA на iPhone

1. Подключите iPhone кабелем, разблокируйте его, при запросе нажмите «Доверять» и введите код-пароль.
2. Запустите Apple Configurator и выделите ваш iPhone в окне «Все устройства».
3. Нажмите **Add → Apps** (Добавить → Приложения).
4. Если появится предложение войти в App Store, нажмите «Отмена»: для локального файла вход не нужен.
5. Нажмите **Choose from my Mac…** и выберите `~/Downloads/APTV_1.5.12.ipa`.
6. Configurator предупредит, что приложение уже установлено, — выберите **Replace** (Заменить).
7. Дождитесь завершения прогресс-бара, не отключая кабель.

Настройки и плейлисты APTV сохраняются, так как замена идёт по тому же bundle ID.

## После установки

1. Откройте APTV на iPhone и убедитесь, что в разделе «О приложении» указана версия 1.5.12.
2. Отключите автообновления: Настройки → App Store → Обновления приложений → выкл. Иначе iOS в фоне снова установит 1.5.13.
3. При ручной проверке обновлений не нажимайте «Обновить всё» — пропускайте APTV.
4. Сохраните IPA в надёжное место (iCloud Drive, внешний диск). Если разработчик удалит старые сборки, скачать их повторно уже не получится, а готовый файл можно установить через Configurator в любой момент.

> **Не передавайте и не публикуйте свой IPA.** В файле записан e-mail вашего Apple ID (в `iTunesMetadata.plist`), и установить его можно только на устройства с вашим аккаунтом.

## Возможные ошибки

| Ошибка | Причина и решение |
|---|---|
| iMazing: «Failed to initiate SRP authentication (GSA)» | Известная проблема iMazing 3.6.x. Используйте ipatool + Configurator, как описано выше. |
| `get-version-metadata` возвращает одинаковую версию для разных ID | Известный баг ipatool. Ориентируйтесь на `releaseDate` и порядок ID в списке. |
| Configurator не видит iPhone | Переподключите кабель, проверьте, что iPhone виден в боковой панели Finder и что вы нажали «Доверять». |
| Ошибка `0xE8008015` при установке | IPA скачан под другим Apple ID. На iPhone в App Store должен быть выполнен вход тем же аккаунтом, что и в ipatool. |
| Приложение не запускается без интернета | При первом запуске iOS проверяет лицензию — подключите iPhone к Wi-Fi. |

## Как вернуться на актуальную версию

Обновите APTV в App Store обычным способом или снова включите автообновления.

## Другие приложения

Этот способ работает для любого приложения из вашей истории покупок — достаточно подставить свой bundle ID из `ipatool search`.
